Basics

Arduino Uno pinout

Hold the board with the USB port on the left, and this is what you see.

DigitalDigital + PWM (~)Analog inPowerGroundSerial, avoid
  • Pins 0 and 1 are used by USB. Leave them free so uploads work.
  • Pin 13 is wired to the small LED on the board, so it blinks with no parts attached.
  • Analog pins can also be used as digital pins (A0 acts as pin 14).

Breadboard: what is joined to what

  • Blue and green strips: the 5 holes in one numbered column (a–e, or f–j) are joined. Plug two legs into the same column and they are connected.
  • Red and dark rails: run the whole length. Connect one to 5V and one to GND, then tap power from anywhere along them.
  • Centre gap: nothing crosses it. Parts that straddle it (like chips) keep their legs separate.

Anatomy of every sketch

Every Arduino program is these two functions. Setup prepares pins; loop is your program.

void setup() {
  pinMode(13, OUTPUT);   // one-time config
  Serial.begin(9600);
}
void loop() {
  digitalWrite(13, HIGH); delay(500);
  digitalWrite(13, LOW);  delay(500);
}

PWM: how analogWrite fakes “in between”

The pin switches on and off hundreds of times a second. The longer it stays on, the brighter an LED looks or the faster a motor spins. Values run from 0 (always off) to 255 (always on) why?, and only on ~ pins.

Voltage divider: how sensors talk to analog pins

Two resistors in a row split 5V. The voltage at the middle depends on the ratio of the two.

  • Potentiometer: turning the knob changes R1 and R2 for you.
  • LDR or thermistor: one of the two resistors changes with light or heat; you add a fixed 10kΩ as the other.
  • Equal resistors give about 2.5V, which reads as about 512.

Functions you will use constantly

digitalRead(pin)Returns HIGH or LOW.
analogWrite(pin, 0–255)PWM output on ~ pins.

When it does not work

Nothing happens at allIs the board selected and the right port chosen? Did the upload finish? Check that GND from the part reaches Arduino GND.
LED stays offFlip it round (long leg to the pin side). Check the pin number matches the code and that pinMode is OUTPUT.
Button flickers or reads random valuesPin is floating why?. Use INPUT_PULLUP, or add a 10kΩ resistor to GND.
Analog values jump aroundCheck the wiper goes to the analog pin and the outer legs to 5V and GND. Add a tiny delay between reads.
Servo jitters or resets the boardPower it from a separate 5V supply and join the grounds.
Serial Monitor shows garbageBaud rate does not match Serial.begin().
Upload failsUnplug anything on pins 0 and 1, and re-check board and port.
Everything stops during delay()Use millis() for timing so inputs keep being read.

Components

LED

Output

A tiny light you can switch on and off, or dim with PWM. It only works one way round and burns out without a resistor why?.

How you use it. Put a 220Ω resistor in series with the long leg. Set the pin HIGH for on, LOW for off. For dimming, use a ~ PWM pin with analogWrite(0–255).

Anode (long leg, +)D9 via 220Ω Current enters here. Connect to the Arduino pin through the resistor.
Cathode (short leg, −)GND Current leaves here. Goes to ground.
pinMode(9, OUTPUT);
digitalWrite(9, HIGH);   // on
analogWrite(9, 128);    // half brightness

Tip: Flat edge on the LED rim = cathode side.

Resistor

Passive

Limits how much current flows why?. It has no direction and no power pins.

How you use it. Place it in series with whatever you want to protect (mostly LEDs). The coloured bands give its value; 220Ω to 1kΩ for LEDs, 10kΩ for pull-ups.

Leg AD9 / source Either leg can go on either side.
Leg BLED anode The other leg continues the circuit.
// no code needed: it is just wiring

Tip: Bigger value = less current = dimmer LED.

Push button

Input

Connects two points while you press it. Your way of telling the Arduino “something happened”.

How you use it. Wire one leg to a digital pin and the opposite-corner leg to GND, then enable the internal pull-up why?. The pin reads HIGH normally and LOW when pressed.

Leg 1D2 Goes to the input pin.
Leg 2 (opposite corner)GND Pressing joins it to leg 1.
pinMode(2, INPUT_PULLUP);
if (digitalRead(2) == LOW) {
  // button is pressed
}

Tip: Legs on the same side are always joined; use diagonal ones.

Potentiometer

Input

A knob that gives a smooth value. Turn it and the middle pin’s voltage slides from 0V to 5V.

How you use it. Outer pins go to 5V and GND (swapping them just reverses the direction). The middle pin, the wiper, goes to an analog pin. analogRead gives 0–1023 why?.

Outer pin 15V One end of the track.
Wiper (middle)A0 The output voltage you read.
Outer pin 2GND Other end of the track.
int v = analogRead(A0);          // 0..1023
int bright = map(v, 0, 1023, 0, 255);
analogWrite(9, bright);

Tip: Use it to tune brightness, speed or servo angle by hand.

Light sensor (LDR)

Input

A resistor whose value drops in bright light. It has no polarity.

How you use it. Arduino reads voltage, not resistance, so pair it with a fixed 10kΩ resistor to make a voltage divider. Read the junction between them.

Leg 15V Top of the divider.
Leg 2A0 + 10kΩ→GND Junction: read here, and run a 10kΩ resistor from it to GND.
int light = analogRead(A0);  // higher = brighter
if (light < 300) { /* it is dark */ }

Tip: Tune the threshold by printing values to Serial first.

Buzzer (active)

Output

Makes a beep when powered. Active buzzers have a built-in tone; passive ones need tone().

How you use it. Plus leg to a digital pin, minus to GND. HIGH beeps, LOW is silent. For a passive buzzer, use tone(pin, frequency).

+ (long leg / marked)D8 Beeps while HIGH.
−GND Return path.
digitalWrite(8, HIGH); delay(200);
digitalWrite(8, LOW);

Tip: Sticker on top? Peel it off and check it is still polarised the right way.

Servo motor (SG90)

Output

Turns to an exact angle (0–180°) and holds it. Good for arms, doors, pointers.

How you use it. Give it 5V power and one PWM-capable signal wire. The Servo library does the timing; you just write the angle.

Brown / blackGND Ground.
Red5V Power. Several servos need an external supply.
Orange / yellowD9 (~) Signal telling it the angle.
#include <Servo.h>
Servo s;
void setup() { s.attach(9); }
void loop() { s.write(90); }

Tip: Jittery? Share GND why? and use a separate 5V source why?.

Ultrasonic sensor (HC-SR04)

Input

Measures distance by sending a sound pulse and timing the echo. Range about 2cm to 4m.

How you use it. Pulse Trig for 10 microseconds, then time how long Echo stays HIGH with pulseIn. Distance in cm ≈ time ÷ 58.

VCC5V Power.
TrigD7 You pulse this to start a measurement.
EchoD6 Goes HIGH for the echo time.
GNDGND Ground.
digitalWrite(7, HIGH); delayMicroseconds(10);
digitalWrite(7, LOW);
long t = pulseIn(6, HIGH);
float cm = t / 58.0;

Tip: Soft or angled surfaces reflect poorly.

Temperature and humidity (DHT11)

Input

Reports temperature and humidity as digital data on a single wire.

How you use it. Install the DHT sensor library. A 3-pin module already has its pull-up resistor; a bare 4-pin sensor needs 10kΩ between DATA and 5V. Read about once every 2 seconds.

VCC / +5V Power.
DATA / SD2 Single-wire digital output.
GND / −GND Ground.
#include <DHT.h>
DHT dht(2, DHT11);
float t = dht.readTemperature();
float h = dht.readHumidity();

Tip: Check the printed labels; pin order varies between modules.

Motion sensor (PIR)

Input

Detects movement of warm bodies like people and pets, and outputs HIGH while it sees it.

How you use it. Treat it as a button that presses itself. Give it about a minute to warm up after power-on. Two trimmers set range and hold time.

VCC5V Power.
OUTD2 HIGH when motion is detected.
GNDGND Ground.
pinMode(2, INPUT);
if (digitalRead(2) == HIGH) {
  // someone moved
}

Tip: Triggers on heat change, so sunlight and heaters can fool it.

Relay module

Output

An electrically controlled switch. Lets a tiny 5V signal turn a lamp, pump or fan on and off why?.

How you use it. The Arduino side has three pins. The load side has screw terminals: COM and NO (normally open) to switch something on. Many modules are active-LOW: LOW turns it on.

VCC5V Powers the coil.
IND4 Control signal.
GNDGND Ground.
pinMode(4, OUTPUT);
digitalWrite(4, LOW);   // click: ON (active-LOW)

Tip: Mains voltage is dangerous. Practise with a low-voltage load first.

LCD 16×2 with I²C backpack

Output

A small text screen that needs only 4 wires thanks to the I²C adapter.

How you use it. Install LiquidCrystal_I2C. SDA and SCL are fixed pins on the Uno (A4 and A5). The address is usually 0x27 or 0x3F.

GNDGND Ground.
VCC5V Power.
SDAA4 I²C data line.
SCLA5 I²C clock line.
#include <LiquidCrystal_I2C.h>
LiquidCrystal_I2C lcd(0x27, 16, 2);
lcd.init(); lcd.backlight();
lcd.print("Hello");

Tip: Blank screen? Turn the blue contrast trimmer on the back.

Transistor (NPN, e.g. 2N2222 or BC547)

Passive

An electronic switch. A tiny current into one pin lets a much bigger current flow through the other two, so a weak Arduino pin can control a motor, buzzer or LED strip why?.

How you use it. Wire the load between the supply and the collector. The emitter goes to GND. Put a 1kΩ resistor between the Arduino pin and the base. HIGH on the pin = load on.

Collector (C)Load − The load’s negative side connects here.
Base (B)D5 via 1kΩ The control input from the Arduino.
Emitter (E)GND Return path. Must join Arduino GND.
pinMode(5, OUTPUT);
digitalWrite(5, HIGH);  // load ON
digitalWrite(5, LOW);   // load OFF

Tip: Pin order differs between models. Check the datasheet for your exact one.

DC motor with L298N driver

Output

A driver board that lets the Arduino switch a motor on, set its speed and reverse it. The motor wires go to its screw terminals, not to the Arduino.

How you use it. Feed the driver’s +12V terminal from a battery pack and join its GND to the Arduino. ENA takes a PWM signal for speed; IN1 and IN2 pick the direction.

ENAD5 (~) PWM speed. Remove its jumper cap first.
IN1D7 Direction input A.
IN2D8 Direction input B. Opposite of IN1 = spins.
GNDGND Join to Arduino and the battery negative.
digitalWrite(7, HIGH); digitalWrite(8, LOW);  // forward
analogWrite(5, 200);                         // speed 0-255
// swap HIGH/LOW on 7 and 8 to reverse

Tip: Motor stuttering? Share GND why? and use fresh batteries.

RGB LED (common cathode)

Output

Three LEDs (red, green, blue) in one case. Mix their brightness to make almost any colour.

How you use it. Each colour leg gets its own 220Ω resistor why? and a PWM pin. The longest leg is the shared ground. A common-anode type goes to 5V instead and works backwards.

RedD9 (~) via 220Ω Red brightness.
Common (longest)GND Shared negative.
GreenD10 (~) via 220Ω Green brightness.
BlueD11 (~) via 220Ω Blue brightness.
analogWrite(9, 255);   // red full
analogWrite(10, 100);  // some green
analogWrite(11, 0);    // no blue  -> orange

Tip: Leg order is R, common, G, B when the flat side is on the left.

7-segment display (TM1637, 4 digits)

Output

A numeric display that shows digits, time or counters. This module has its own chip, so it needs only 2 signal wires.

How you use it. Install the TM1637Display library. CLK and DIO can be any two digital pins; you tell the library which.

CLKD2 Clock line.
DIOD3 Data line.
VCC5V Power.
GNDGND Ground.
#include <TM1637Display.h>
TM1637Display d(2, 3);   // CLK, DIO
d.setBrightness(5);
d.showNumberDec(1234);

Tip: Plain single-digit displays have 10 pins; this module is far easier to start with.

Joystick module

Input

Two potentiometers and a button in one stick. It reports left-right, up-down and a press on the stick.

How you use it. X and Y are analog values (about 512 when centred). The press switch behaves like a push button: use INPUT_PULLUP why? and read LOW.

GNDGND Ground.
+5V5V Power.
VRxA0 Left-right position.
VRyA1 Up-down position.
SWD2 Press switch, LOW when pushed.
pinMode(2, INPUT_PULLUP);
int x = analogRead(A0);   // 0..1023
int y = analogRead(A1);
bool pressed = digitalRead(2) == LOW;

Tip: Print X and Y to Serial first to find your stick’s real centre.

Quick doubts

Why does an LED need a resistor?

An LED does not limit its own current. Once the voltage across it passes roughly 2V it lets almost anything through, and an Arduino pin can only give about 20mA safely. Without a resistor the LED, the pin, or both get damaged. The resistor soaks up the extra voltage and sets the current. The sum is (5V − 2V) ÷ 0.015A ≈ 200Ω, so 220Ω is the standard choice. A larger value only makes the LED dimmer.

Why must every part share a ground?

A voltage is always measured between two points. When the Arduino says “5V” it means 5V above its own GND. A sensor, motor driver or battery with a separate ground has no common reference, so signals read randomly or not at all. Joining the grounds gives every part the same 0V to measure from. Rule of thumb: whenever you add an external power source, connect its GND to the Arduino GND.

What is a floating pin, and why use a pull-up?

An input pin connected to nothing picks up stray electricity and reads random HIGH and LOW. A pull-up resistor gently ties the pin to 5V, so it reads a steady HIGH when nothing is pressed. Pressing the button connects the pin to GND, which wins and reads LOW. INPUT_PULLUP switches on a resistor already inside the chip, so no extra part is needed. The side effect: pressed = LOW.

Why can’t a pin power motors and other big loads?

An Arduino pin gives about 20mA, and the whole 5V rail from USB only about 500mA. Motors, relay coils, LED strips and servos under load need far more, and motors also send voltage spikes back. So use the pin only as a signal into a transistor, relay or motor driver, and power the load from its own supply with the grounds joined.

Why is analogRead 0–1023 but analogWrite 0–255?

They use different hardware. Reading uses a 10-bit converter: 2¹⁰ = 1024 steps. Writing uses 8-bit PWM: 2⁸ = 256 steps. To convert, use map(v, 0, 1023, 0, 255) or simply v / 4.
